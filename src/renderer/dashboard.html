欢迎使用 Token消费器

填入你的 DeepSeek API Key，即可看到剩余金额；把客户端指向本地代理后，还能看到每一次调用的 token 消耗。

Key 仅保存在本机 data/config.json，不会上传到任何服务器。

使用说明

  1. 填写 API Key：在「设置」里填入你的 DeepSeek API Key，保存后自动显示剩余金额。
  2. 指向本地代理：把 ChatBox、Cherry Studio、NextChat、Claude Code 等客户端的 Base URL 填为 http://127.0.0.1:8787（API Key 随便填，实际使用本软件里保存的 Key）。
  3. 实时查看：悬浮小窗显示余额与今日消耗，仪表盘显示每一次请求的 token 明细。
  4. 未走代理的调用（DeepSeek 网页端、官方 App、直接连 api.deepseek.com 的代码）只能看到余额变化，看不到单次明细。
